# 直播驾驶舱与复盘原型

- `live.html`：统一实时驾驶舱，顶层可切换“直播中 / 下播复盘”。下播复盘使用整场数据曲线、分轨时间轴和单一动态详情区。
- `ended.html`：旧入口兼容页，直接进入 `live.html?mode=review`。
- `review.html`：正式复盘留存页，保留管理后台导航，展示运营复盘正文、主播复盘报告、下场任务和折叠数据快照。
- `app.js`：统一演示场次数据、时间轴、复用详情组件、录音生命周期与正式正文保存交互。

直接打开 `live.html` 即可体验。页面中的人物、商品和数值均为产品原型演示数据，不是生产经营事实。
